# RecordMC

[English](README.md) | [日本語](README-ja.md)

Minecraft Java版 (Fabric) 向けのゲーム内動画録画Modです。

---

## 概要
**RecordMC** は、Minecraftのプレイ画面をゲーム内からワンキーで手軽に録画できるModです。  
MaLiLibをベースにした設定GUIを搭載しており、`H + R` キーまたはModMenuから各種設定やキーバインドを直感的にカスタマイズできます。

---

## 主な特徴

- **ワンキー録画**: `F9`（変更可能）を押すだけで録画の開始・停止を即座にトグル。
- **洗練された設定GUI**: `H + R` キーまたはModMenuから設定メニューを開き、FPS・画質・エンコードプリセット・出力フォーマット・ホットキー等を視覚的に設定可能。
- **完全な画面キャプチャ**: HUD、チャット、インベントリ、チェスト、開いているGUI画面など、プレイヤーが見ている実際の画面全体をそのまま動画として記録。
- **ゲーム内音声のみを収録**: Minecraft内部の純粋なゲーム音のみを収録。
- **多彩な出力形式**: 出力コンテナ形式をボタン1つで切り替え可能。MP4、MOV、MKV、WebM（デフォルト: `mp4`）に対応。
- **録画中インジケーター**: 録画中は画面右上に点滅する赤いマーク（● REC）と経過時間が表示され、録画状況が一目で把握可能。
- **自動保存 & クリップボード自動コピー**: 保存完了後、**動画ファイルが自動でOSのクリップボードにコピー**されるため、DiscordやSNS等にそのまま `Ctrl + V` で即座に貼り付け・アップロード可能。
- **多言語対応**:
  - 日本語、英語、簡体字中国語、繁体字中国語、韓国語、ロシア語、ドイツ語、フランス語、スペイン語（欧州/ラテンアメリカ）、ポルトガル語、イタリア語、ポーランド語、ウクライナ語など14言語のネイティブ言語設定に対応。
  - 登録外の言語が選択された場合でも、**その言語に最も近い言語グループを自動判定して最適な言語で表示**します。

## 必要環境

| 項目 | 要件 |
|---|---|
| **Minecraft** | `1.16.1` `1.18` `1.18.1` `1.18.2` `1.19.4` `1.20` `1.20.1` `1.20.6` `1.21` `1.21.1` `1.21.4` `1.21.5` `1.21.6` `1.21.7` `1.21.8` `1.21.9` `1.21.10` `1.21.11` |
| **Fabric Loader** | `>= 0.14.0` |
| **Fabric API** | 各バージョン対応版 |
| **MaLiLib** | 各バージョン対応版 (必須) |
| **ModMenu** | 任意 |
| **FFmpeg** | システムにインストールされていること (PATHに通っているか、設定画面でパスを指定) |

### FFmpegのインストールについて
Linux (Ubuntu/Debian):
```bash
sudo apt update && sudo apt install -y ffmpeg
```
Arch Linux:
```bash
sudo pacman -S ffmpeg
```
Windows:
公式サイト等から `ffmpeg.exe` をダウンロードし、PATHに追加するか、本Modの設定画面で実行ファイルのフルパスを指定してください。

## 操作方法

- **設定メニューを開く**: `H + R` (デフォルト)
- **録画の開始 / 停止**: `F9` (デフォルト)

> [!NOTE]
> キー割り当ては `H + R` で開く設定メニュー内の「ホットキー (Hotkeys)」タブ、または ModMenu の設定からいつでも変更可能です。

---

## 設定項目一覧

設定メニュー（`H + R`）または `config/recordmc.json` から以下の項目を設定できます：

### 一般設定 (Generic タブ)
| 設定名 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `fps` | 整数 | `60` | 録画フレームレート (1〜240 FPS) |
| `crf` | 整数 | `20` | H.264 画質設定 (0〜51, 低いほど高画質・ファイルサイズ大、推奨: 18〜23) |
| `preset` | 選択肢 (ボタン式) | `ultrafast` | FFmpegエンコードプリセット。ボタンを押すたびに循環切り替え (`ultrafast`, `superfast`, `veryfast`, `faster`, `fast`, `medium`) |
| `videoFormat` | 選択肢 (ボタン式) | `mp4` | 出力ファイル形式。ボタンを押すたびに循環切り替え (`mp4`, `mov`, `mkv`, `webm`) |
| `recordAudio` | 真偽値 (ボタン式) | `true` | ゲーム内音声（BGM/SE/環境音）を録音するかどうか |
| `showIndicator` | 真偽値 (ボタン式) | `true` | 録画中に画面右上に赤いRECマークと経過時間を表示するかどうか |
| `copyToClipboard` | 真偽値 (ボタン式) | `true` | 録画完了時に動画ファイルを自動でOSのクリップボードにコピーするかどうか |
| `customFfmpegPath` | 文字列 (パス) | `""` (空欄) | FFmpeg実行ファイルパス。空欄で自動検出。絶対パス、相対パス、コマンド名に対応（ホバーで現在の有効パスを表示） |
| `customVideoDir` | 文字列 (パス) | `""` (空欄) | 動画保存先フォルダ。空欄で `./video` に保存。絶対パスおよびゲームフォルダからの相対パスに対応（ホバーで現在の有効パスを表示） |

### ホットキー (Hotkeys タブ)
| 設定名 | デフォルト | 説明 |
|---|---|---|
| `openGui` | `H,R` | RecordMCの設定メニュー (GUI) を開く |
| `toggleRecording` | `F9` | 録画の開始 / 停止を切り替える |
